# YesOffice — лендинг стартапа

Одностраничный сайт платформы **YesOffice** для управления коммерческой недвижимостью: аналитика, автоматизация и контроль в реальном времени на базе Big Data.

## Стек

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS 4**
- **EmailJS** — отправка заявок на демо

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:5173](http://localhost:5173).

## Скрипты

| Команда           | Описание                    |
| ----------------- | --------------------------- |
| `npm run dev`     | Локальная разработка        |
| `npm run build`   | Сборка в `dist/`            |
| `npm run preview` | Просмотр production-сборки  |
| `npm run lint`    | Проверка ESLint             |

## Структура проекта

```
src/
├── components/
│   ├── layout/       # Header, Footer, Layout
│   ├── sections/     # Секции лендинга
│   └── ui/           # Переиспользуемые компоненты
├── constants/        # Тексты, данные, навигация
├── hooks/            # useInView, useCountUp
├── models/           # TypeScript-типы
├── pages/            # HomePage
├── services/         # sendDemoEmail (EmailJS)
└── utils/            # Вспомогательные функции
```

## Секции лендинга

| Якорь                 | Секция              |
